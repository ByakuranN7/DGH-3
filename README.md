#Repositório de desenvolvimento da versão digital de Don't Get Hacked.

Um projeto de conclusão de curso com foco no ensino de cibersegurança no ambiente educacional, especialmente universidades.

Os scripts se encontram em Assets -> My Game -> Scripts. Dentro desta pasta, a grande maioria está classificado por cena, sendo assim eles estão dentro de pastas que possuem o nome de suas respectivas cenas onde aparecem pela primeira vez ou quando são exclusivos da cena.

O node.js (nomeado de server.js) se encontra em UnityNodeLogin.

A pasta "My Game" inclui os prefabs, imagens, fontes customizadas, todos os objetos do tipo carta e também todas as cenas, além dos scripts.
